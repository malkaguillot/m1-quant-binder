# Sandbox R — M1 Analyses quantitatives des données (UGA)

Ce dépôt fournit uniquement l'environnement R (packages) utilisé pour lancer
un sandbox RStudio en ligne via [mybinder.org](https://mybinder.org), sans
nécessiter de compte ni d'installation locale pour les étudiants.

Le contenu pédagogique complet (slides, exercices, données) reste dans le
dépôt principal du cours.

## Lancer le sandbox

Cliquer sur le badge ci-dessous (peut prendre 1-2 minutes à démarrer) :

[![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/malkaguillot/m1-quant-binder/main?urlpath=rstudio)

Un environnement RStudio s'ouvre dans le navigateur avec les packages du
cours déjà installés (`tidyverse`, `dslabs`, `infer`, `moderndive`, etc.).

⚠️ L'environnement est temporaire : toute donnée non téléchargée est perdue
à la fermeture de la session.
